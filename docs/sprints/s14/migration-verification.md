## Pre/post inventory (losslessness)

- **Pre-image:** the migration wrote the authoritative source inventory to
  [migration-provenance.md](../../history/migration-provenance.md) — 208 rows
  (146 regular files with SHA-256, 62 directories), each row
  `type<TAB>sha256<TAB>legacy-path<TAB>Book-path`.
- **Post-image:** every one of the 146 file targets under `docs/` was rehashed
  after cutover and compared against the pre-image SHA-256.
- **Result:** **146/146 files match by content hash; 0 missing, 0 mismatch.**
  Directory structure maps one-to-one per the recorded path mappings.

Reproduce from the repository root:

```bash
# Recompute each Book target's hash and compare to the provenance pre-image.
awk -F '\t' '/^    F\t/ { gsub(/^    /,""); print $2, $4 }' \
  docs/history/migration-provenance.md |
while read -r want path; do
  got=$(sha256sum "$path" | cut -d' ' -f1)
  [ "$got" = "$want" ] || echo "MISMATCH $path"
done
echo "done — no MISMATCH lines means 1:1 preservation"
```
