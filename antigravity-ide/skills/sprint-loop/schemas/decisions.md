# Schema: `decisions.md`

Lives at `decisions.md` in the project root — an ADR-lite architectural decisions log, persistent across all sprints. The Loop Phase appends an entry per architectural decision made during the sprint.

```markdown
## YYYY-MM-DD — <short title> (sprint N)
- **Context:** Why this decision needed to be made.
- **Decision:** What we chose.
- **Alternatives considered:** What we did not choose, and why.
- **Consequences:** What this commits us to going forward.
```
